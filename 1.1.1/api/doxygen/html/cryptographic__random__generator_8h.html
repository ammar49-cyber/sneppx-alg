void SNEPPX_random_bytes_set_seed ( const uint8_t  seed[32])

Seed the test-only deterministic RNG.

When seeded, all SNEPPX_random_bytes output becomes reproducible from the given 32-byte seed (SHA-512 hash-chain). Intended for known-answer tests; production code must NOT call this. Call SNEPPX_random_bytes_clear_seed to restore OS/CSPRNG randomness.

Parameters
seed[in] 32-byte seed value.
