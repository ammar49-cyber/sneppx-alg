int SNEPPX_ed25519_verify_compat ( const uint8_t *  sig,

Verify Ed25519 with optional legacy-hash fallback.

Verify Ed25519 with optional legacy-hash fallback for migration.

First attempts verification with the RFC-8032 compliant SHA-512. If that fails with an invalid-signature result (0) and allow_legacy is non-zero, recomputes the challenge hash using the legacy (pre-fix) SHA-512 digest and retries. This allows manifests signed before the SHA-512 length-encoding fix to still be verified.

Parameters
sig[in] 64-byte raw signature (R || S).
m[in] Message bytes.
mlen[in] Message length.
pk[in] 32-byte public key.
allow_legacy[in] If non-zero, fall back to legacy SHA-512 on failure.
Returns
1 on valid, 0 on invalid, -1 on error.
