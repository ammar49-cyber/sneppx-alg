Detailed Description

Universal model configuration system.

Provides a unified ModelConfig structure that can represent any model architecture (Transformer, ViT, Diffusion, RNN, GAN, GCN, and sneppx primitives HSS/NPE/SER/ARC). Supports JSON serialization, file I/O, validation, and preset configurations.
