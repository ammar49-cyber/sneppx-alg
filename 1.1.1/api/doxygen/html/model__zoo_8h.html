Detailed Description

Model configuration presets and weight conversion for supported architectures.

Defines configuration structs for LLaMA 2/3, Mistral, Qwen 2, and DeepSeek V2, along with factory functions to instantiate named presets by family + size. Also provides NTK-aware RoPE scaling via SNEPPX_llm_config_extend_context() for extending context windows up to 128K tokens.

Extend a model's context window using NTK-aware and YaRN RoPE scaling.

Adjusts max_position_embeddings, rope_theta, and scaling factors so the model can handle sequences up to target_len. Supports 128K context extension for all architectures (LLaMA 2/3, Mistral, Qwen 2, DeepSeek V2).

Parameters
cfgPointer to the configuration (modified in place).
target_lenDesired maximum sequence length (e.g. 131072 for 128K).
Returns
0 on success, nonzero if target_len is invalid or scaling fails.
