# Migrating from v0.9.x to v1.0.0

## Overview

v1.0.0 is the first stable release of SNEPPX-Algo. All APIs introduced in the
0.9.x cycle are now frozen. No breaking changes to existing functionality.

## What Changed

### Version Bump
All version manifests have been bumped from `0.9.7.890e` to `1.0.0`.

### Bugfixes

1. **`model_card_to_json` hang fixed** — The 3rd argument to `json_escape_append`
   in the tags loop was `&buf_len` instead of `&buf_size`, causing an infinite
   realloc loop when serializing cards with tags. If you called `model_card_to_json`
   on a card with tags, it would hang. Now fixed.

2. **`weight_collection_add` buffer overrun fixed** — `memcpy` used `t->data_size`
   (the allocated size, which may be larger) instead of `data_size` (the actual
   data size to copy). If `data_size < t->data_size`, this could read past the
   source buffer. Now clamped to `min(data_size, t->data_size)`.

3. **`test_model_card.c` crash fixed** — Missing `#include <stdlib.h>` caused
   `malloc`/`free` to be assumed `extern int` (32-bit), truncating 64-bit
   pointers on x64 → access violation. Test now uses proper setters instead of
   raw `strdup` into struct fields.

4. **Qwen2Config/DeepSeekV2Config `max_seq_len` fixed** — The `max_seq_len`
   field was declared both as a `@dataclass` field and a `@property` (read-only),
   causing `AttributeError: property has no setter` on construction. Removed
   the duplicate field; `max_seq_len` is now only a `@property` that returns
   `self.max_position_embeddings`.

### New Features

- **Model Zoo (Phase 1)**: `get_model_config()`, `from_pretrained()`,
  `build_model_from_config()`, `ModelHub`, `ModelConfig` dataclass,
  `ModelCard`, `WeightCollection`, `ModelFactory` (C++ RAII).
- **Distributed Training (Phase 2)**: ZeRO-1/2/3, pipeline/tensor/expert
  parallel, elastic training, checkpoint coordinator.
- **Advanced Architectures (Phase 3)**: Differential Attention, Mamba-2,
  FlexAttention, Mixture of Depth, YaRN, ALiBi.
- **Quantization (Phase 5)**: INT8, FP8, AWQ, GPTQ in C + CUDA + Python.
- **Checkpointing (Phase 6)**: Async save/load, heartbeat, elastic training.
- **Profiling (Phase 7)**: `SNEPPX_Profiler`, `SNEPPX_Logger`, sanitizer scripts.

### Removals

- **CI/CD files removed**: `.github/workflows/`, `dependabot.yml`,
  `CODEOWNERS` — these were not actively maintained and caused confusion.
  Builds remain reproducible via CMake/Docker.

## Upgrade Steps

1. Update your dependency to `sneppx-alg>=1.0.0`.
2. Rebuild from source: `cmake -B build -G Ninja && cmake --build build`
3. Run tests: `cd build && ctest -C Release --output-on-failure`

## Compatibility

- C API: Fully backward compatible. All `model_card_*`, `model_config_*`,
  `model_registry_*`, `weight_*` functions unchanged.
- C++ API: New `ModelFactory` class added. All existing headers unchanged.
- Python API: New top-level functions (`get_model_config`, `from_pretrained`,
  `build_model_from_config`). All existing classes unchanged.
- Build system: Same CMake options as v0.9.x. No changes required.
