# Release v1.0.0 — Stable Release

**Date:** 2026-07-25
**Tag:** `v1.0.0`
**Type:** Major — first stable release

## Summary

v1.0.0 is the first stable release of SNEPPX-Algo, marking the completion of
all 8 development phases. The API is frozen for backward compatibility. Every
component — from the tensor engine and autodiff through the security layers,
distributed training, quantization, and model zoo — is fully implemented and
tested.

## What's new since v0.9.7.890e

### Phase 1 — Model Zoo

- **Model Config Schema**: C config API with JSON serialize/parse, presets for
  LLaMA 2/3, Mistral, Qwen 2, BERT, ViT, SDXL
- **Model Registry**: Registration, discovery, search, save/load, deprecation
- **Pretrained Weights**: `WeightCollection` API, dtype conversion (f32/f16),
  INT8 quantization, safetensors/gguf/npz loaders
- **Model Cards**: Metadata with JSON serialization, validation, file I/O
- **Python ModelConfig**: Dataclass with JSON serialization, validation,
  C config conversion, registry integration
- **Python ModelHub**: `ModelHub` class with `from_pretrained`, `save_pretrained`
- **C++ Model Factory**: RAII wrappers, `ModelFactory` with create/save/load
- **Integration Tests**: C + Python roundtrip tests covering full pipeline

### Bugfixes

- Fixed `model_card_to_json` infinite realloc loop (tags serialization)
- Fixed `weight_collection_add` buffer overrun (memcpy used wrong size)
- Fixed `test_model_card.c` crash (missing stdlib.h + strdup on MSVC x64)
- Fixed Qwen2Config/DeepSeekV2Config max_seq_len property/dataclass conflict

### Full Regression Suite

- **C**: 43/43 model zoo tests pass
- **C++**: 11/11 factory tests pass
- **Python**: 22/22 tests pass

## Breaking Changes

None. All APIs remain backward-compatible with v0.9.x.

## Upgrading

```bash
git fetch --tags
git checkout v1.0.0
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

See `docs/migration/v0.9.x-to-v1.0.0.md` for details.
