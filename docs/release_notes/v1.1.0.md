# Release v1.1.0 — Serving, Fine-Tuning, and Evaluation

**Date:** 2026-07-27
**Tag:** `v1.1.0`
**Type:** Minor — feature release

## Summary

v1.1.0 introduces production model serving with continuous batching and quantized inference, fine-tuning adapters (LoRA/QLoRA), alignment trainers (DPO/GRPO), standard evaluation harnesses, and dedicated CLI tools (`sneppx-eval`, `sneppx-quantize`, `sneppx-rlhf`, `sneppx-serve`).

## What's New

### 1. Production Model Serving
- **Continuous Batching**: `ContinuousBatchScheduler` with dynamic request queue, FCFS/priority scheduling, token-by-token generation loop.
- **Quantized Serving**: `QuantizedModelConfig`, weight quantization/dequantization, and memory size estimation.
- **Inference Server**: FastAPI endpoints (`/v1/generate/continuous-batch`, `/v1/models/quantize`) compatible with OpenAI API specs.

### 2. Fine-Tuning & Alignment
- **LoRA / QLoRA**: Low-Rank Adaptation layers with rank/alpha configuration and merged weight export.
- **DPO / GRPO Trainers**: Direct Preference Optimization and Group Relative Policy Optimization alignment training with log-probability extraction.

### 3. Evaluation & Benchmarks
- **Eval Harness**: Synthetic and standardized benchmark suites for MMLU, GSM8K, and HumanEval evaluation.

### 4. CLI Tools
- `sneppx-eval`: Model evaluation against standard benchmarks.
- `sneppx-quantize`: Quantization to INT8, INT4, FP8, AWQ, and GPTQ.
- `sneppx-rlhf`: RLHF and alignment training workflows.
- `sneppx-serve`: Production inference server launcher.
