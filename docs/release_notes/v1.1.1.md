# Release v1.1.1 — Security Hardening, C HTTP Server, and Packaging

**Date:** 2026-08-01
**Tag:** `v1.1.1`
**Type:** Patch — security & infrastructure release

## Summary

v1.1.1 delivers rigorous C security hardening across all core modules, a standalone C HTTP server control plane with OAuth/Bearer auth middleware, and polished Python packaging for wheel distribution.

## What's New

### 1. C Security Hardening
- Replaced unsafe C functions (`gets`, `scanf`, `strcpy`, `sprintf`, `alloca`) across 8 files (`model_factory.cpp`, `vit.c`, `numpy_format.c`, `onnx_format.c`, `pth_format.c`, `safetensors.c`, `http_auth.c`, `s9_extensions.c`).
- Fixed `dilithium_zetas[256]` twiddle factor table corruption in ML-DSA signature verification.
- Fixed Kyber NTT twiddle table, Montgomery reduction, and relaxed DRBG minimum entropy requirements.

### 2. C HTTP Server Control Plane
- New `net/http/http_api.{h,c}` module registering `/v1/health`, `/v1/models`, `/v1/models/{id}`, and `/v1/generate` mirroring Python inference responses.
- Route parameter capture (`{param}`) via `SNEPPX_http_request_param`.
- Robust TCP body reading loop satisfying `Content-Length`.
- `examples/http_server_demo.c` demo with public health/models and Bearer token-protected generate endpoints.

### 3. Packaging & Build
- Standardized on Ninja generator across all CMake presets (`debug`, `release`, `asan`, `cuda`, `python`, `minimal`).
- Automatic x64 MASM assembler resolution (`ml64` next to `cl.exe`) for Windows MSVC + Ninja builds.
- Python wheel metadata & tagging (`cp311-cp311-win_amd64`) with optional FastAPI imports.
